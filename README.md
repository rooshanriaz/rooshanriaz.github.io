# Rooshan

Personal site: notes, about, resume, and contact. Built with Astro.

```sh
npm install
npm run dev
```

Edit `src/site.config.ts` for name, email, and social links. Write posts in `src/content/posts/`. Set `PUBLIC_FORM_ENDPOINT` in `.env` if you want the contact form to POST to Formspree (or similar); otherwise it opens a mail draft.
